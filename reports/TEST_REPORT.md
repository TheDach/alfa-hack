**Средний локальный балл: 16.08341234 / 100.**

Подстановка в формулы:

```text
S_reg = 100 * max(0, 1 - 41.014913869780 / 43.196225380404)
      = 5.04977343
S_cls = 100 * max(0, (0.652826938515 - 0.523656674940) / (1 - 0.523656674940))
      = 27.11705125
score = (S_reg + S_cls) / 2 = 16.08341234
```

Это локальная оценка относительно заранее фиксированного RandomForest, а не официальный public score. Опубликованный `baseline.py` представляет собой LLM-агента: он не задает фиксированную модель и не содержит значений B_RMSE и B_F1. Скрытые ответы test и официальные значения бейзлайна отсутствуют. Поэтому официальный балл сейчас не вычислим.

## Протокол

Из публичного train один раз выделено 20% строк с seed `20261023`. Регрессия: 42646 строк на обучение агента и 10662 на внешний контроль. Классификация: 70137 и 17533 соответственно; split стратифицированный.

Агент получает только обучающие строки с target и внешний holdout без target. В sample целевые значения заменены заглушкой. Внутри агент отдельно выделяет fit, calibration и validation; все преобразования обучаются на fit. Калибровка Macro F1 использует calibration, выбор модели и смеси использует validation. Внешние цели не участвуют в этих действиях.

Локальный ориентир: `RandomForest(n_estimators=200, max_depth=12, min_samples_leaf=2, random_state=42)`. Преобразования ориентира обучены только по тем же 80% train. Параметры ориентира не подбирались на holdout. Финальные метрики получены из сохраненных CSV, после переобучения выбранных моделей на этих 80%.

На задачу задан бюджет 600 секунд и до 8 CPU. Регрессия завершилась за 526.4 секунды, проверено 8 гипотез, остановок по таймауту: 1. Классификация завершилась за 473.4 секунды, гипотез: 5, остановок по таймауту: 3. В обоих случаях статус `complete`, итоговое обучение завершено. После таймаутов последний корректный CSV сохранялся.

Результат измерен в режиме `--offline`: доступа к организаторскому Qwen нет. API-контракт проверен имитацией ответов; качество реального планирования Qwen этим прогоном не измерено. В production-запуске по умолчанию доступно 10320 секунд, максимум 8 CPU и 27 GiB для обучающего процесса.
